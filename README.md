# Scanner Conte LIVE — PWA da pubblicare senza dati personali

Questo ZIP contiene la PWA con un archivio **vuoto**. Non espone le 75 giocate o i risultati personali nel repository pubblico.

1. Crea un repository GitHub dedicato `scanner-conte-live` e carica **solo questo ZIP estratto**.
2. Attiva GitHub Pages dalla branch `main`, cartella `root`.
3. Apri l'app dall'URL GitHub Pages, se desideri installala dal browser Android.
4. Nell'app: **Dati → Importa backup JSON**, scegli il file `storico_iniziale.json` del pacchetto personale, non caricarlo su GitHub.
5. I dati importati restano nel localStorage di **quel browser**; fai backup regolari. Il cloud privato multi-dispositivo arriverà in una fase successiva.

Limitazioni: no quote live, no scanner automatico, no scommesse automatiche. Le API devono ancora essere collegate e verificate.
